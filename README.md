# Krunker.io Game Testing Project

This project demonstrates manual QA testing of the browser FPS game Krunker.io.

## Test Scope

The following gameplay features were tested:

- Match start
- Player movement
- Shooting mechanics
- Reload functionality
- Respawn system
- Score updates
- Weapon switching
- Server selection
- Map loading
- Exit to lobby

## Test Artifacts

Repository includes:

- Test cases
- Bug reports
- Test summary
- Gameplay screenshots

## Bugs Found

Two issues were identified during testing:

1. Browser tab crash during gameplay
2. Low visual contrast between weapon model and ground textures
