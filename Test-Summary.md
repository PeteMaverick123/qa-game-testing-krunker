# Test Summary – Krunker.io

Tester: Petr Dobias  
Platform: Browser (Google Chrome)  
Game type: Browser FPS multiplayer

## Scope of testing

The following gameplay features were tested:

- Starting a match
- Player movement
- Shooting mechanics
- Reload system
- Respawn system
- Score update
- Weapon switching
- Exit to lobby
- Server selection
- Map loading

## Test results

Total test cases: 10  
Passed: 8  
Failed: 2

## Issues found

### 1. Browser crash during gameplay
Severity: High

During gameplay the browser tab closed unexpectedly while the match was running.

### 2. Low visual contrast between weapon model and ground textures
Severity: Medium

Some weapon models visually blend with the ground texture, which can reduce gameplay readability.
